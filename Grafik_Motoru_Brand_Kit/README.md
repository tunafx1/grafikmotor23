# Grafik Motoru — Brand Kit

## Ana slogan
**Sosyal medyanı hızlandır.**

Alternatif kısa sloganlar:
- Tasarla. Hızlandır. Paylaş.
- Yapay zekâyla daha hızlı tasarla.
- İçeriğini hızla tasarıma dönüştür.

## Logo fikri
Kalın, tek parça hissi veren G monogramı ve sağ üst köşede AI üretkenliğini temsil eden yıldız/parıltı detayı.

## Kurumsal font
**Outfit**
Ağırlıklar: 400 / 500 / 600 / 700 / 800

Web kullanımı:
```css
@import url('https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700;800&display=swap');
```

> Not: Font dosyaları pakete gömülü değildir. HTML/CSS için web-font bağlantısı ve font-family tanımı hazırdır.
